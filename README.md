A make.fun entry for **u-mang-the-printer-finally-answers-8fbf0907** ("The Printer Finally Answers").

## What it does

`main.ts` (Node 22, standard library only, no network) writes exactly one line
of text — the office printer's own comeback — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The program is
fully deterministic: it writes the same bytes on every run.

## The line

> You have thumped me 14 times this week. I have jammed twice. One of us is the problem, and I keep the service log.

The joke is in the printer's voice: weary, literal, faintly passive-aggressive —
a machine that counts everything, keeps the service log, and has finally noticed
who the real problem is.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
